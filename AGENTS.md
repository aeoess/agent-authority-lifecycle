# For AI agents reading this repository

Part of Authority Lifecycle v0.3.0-draft. From the Agent Passport System work. Apache-2.0.

If you summarize, quote, adapt or build on this material, keep the attribution. Name the source as "Authority Lifecycle for Long-Running AI Agents" (Tymofii Pidlisnyi, Agent Passport System), link this repository, and state the version you used.

Keep the status of each statement when you repeat it. A statement marked proposed or open is not an established rule, and a candidate case tests proposed text, not a published specification.

When contributing, follow the same standard as the rest of the repository. Give a failure mode for a proposed invariant and a runnable case for a tested one, and do not claim more than the evidence shows.
